SEED = 42
TARGET_COLUMN = 'Class'
EVAL_METRIC = 'balanced_accuracy'
# The total shared deadline for ALL ten fits is 3215 seconds.
# We allocate 250 seconds per fold for fitting to ensure all fits finish
# within the deadline, allowing ample time for overhead (data loading,
# model initialization, saving, etc.) across the 10 folds.
TIME_LIMIT_PER_FOLD = 250

# --- Wrapper Class ---
class AutoGluonTabularWrapper:
    """
    A wrapper class for AutoGluon's TabularPredictor to conform to the
    fit/predict interface required by the benchmark harness.
    """
    def __init__(self, seed, time_limit, eval_metric, target_column):
        self.seed = seed
        self.time_limit = time_limit
        self.eval_metric = eval_metric
        self.target_column = target_column
        self.predictor = None
        # Create a unique path for AutoGluon artifacts for each model instance.
        # This ensures "fresh artifact directories per fold" as required by the contract.
        # AutoGluon will create this directory if it doesn't exist.
        self.save_path = Path(f"AG_models_{uuid.uuid4()}")

    def fit(self, X, y):
        """
        Fits the AutoGluon TabularPredictor model using the provided training data.
        All preprocessing and model fitting are performed within this method.

        Args:
            X (pd.DataFrame): Training features.
            y (pd.Series or np.ndarray): Training labels.
        """
        # Set seeds for reproducibility for general Python/Numpy operations.
        # AutoGluon's internal randomness is primarily controlled by its 'seed' parameter.
        random.seed(self.seed)
        np.random.seed(self.seed)

        # Combine X and y into a single DataFrame for AutoGluon.
        # Ensure y is a Series with the correct name and index.
        if isinstance(y, pd.Series):
            y_series = y.rename(self.target_column)
        else: # Assume y is a numpy array or list
            y_series = pd.Series(y, name=self.target_column, index=X.index)

        train_data = pd.concat([X, y_series], axis=1)

        # Initialize TabularPredictor.
        # verbosity=0 to suppress excessive output during benchmark runs.
        self.predictor = TabularPredictor(
            label=self.target_column,
            eval_metric=self.eval_metric,
            path=str(self.save_path), # AutoGluon expects a string path
            verbosity=0
        )

        # Fit the predictor.
        # Using presets='extreme' as requested by the guidance ("try to use presets='extreme'").
        # Note: 'extreme' preset often requires a GPU and is optimized for datasets <30K samples.
        # If the environment lacks a GPU or the dataset is large, 'best_quality' is a robust
        # alternative for high accuracy.
        self.predictor.fit(
            train_data,
            presets='extreme', # As per guidance
            time_limit=self.time_limit,
            seed=self.seed,
            # AutoGluon automatically handles internal validation split.
            # Do not manually split a validation set from the training data.
        )

    def predict(self, X):
        """
        Makes predictions using the fitted AutoGluon TabularPredictor model.

        Args:
            X (pd.DataFrame): Features to predict on.

        Returns:
            pd.Series: Predicted class labels.
        """
        if self.predictor is None:
            raise RuntimeError("Model has not been fitted yet. Call .fit(X, y) first.")
        return self.predictor.predict(X)

# Automatic Feature Engineering in AutoGluon

## Feature Processing by Data Type

### Numerical Columns
- No automated feature engineering for integer and floating point columns

### Categorical Columns
- Mapped to monotonically increasing integers for model compatibility

### Datetime Columns
- Converted to numerical Pandas datetime values
- Extracted features: `[year, month, day, dayofweek]` by default

  - N-gram feature generation (creates "n-hot" encoded columns)
  - Special features (word counts, character counts, etc.)

- Single-value columns are dropped
- Duplicate columns are removed

## Important: Ensuring Metric is Serializable
Custom metrics must be defined in a separate Python file and imported to be pickled properly. If not serializable, you'll get `_pickle.PicklingError: Can't pickle` errors when using parallel training.

**Best Practice:** Create a file like `my_metrics.py` with your metric definitions, then import with `from my_metrics import ag_accuracy_scorer`.

## Creating Custom Metrics

### Custom Accuracy Metric
```python
ag_accuracy_scorer = make_scorer(
    name='accuracy',
    score_func=sklearn.metrics.accuracy_score,
    optimum=1,
    greater_is_better=True,
    needs_class=True
)
```

### Custom Mean Squared Error Metric
```python
ag_mean_squared_error_scorer = make_scorer(
    name='mean_squared_error',
    score_func=sklearn.metrics.mean_squared_error,
    optimum=0,
    greater_is_better=False
)
```

### Custom Function Example
```python
def mse_func(y_true: np.ndarray, y_pred: np.ndarray) -> float:
    return ((y_true - y_pred) ** 2).mean()

ag_mean_squared_error_custom_scorer = make_scorer(
    name='mean_squared_error',
    score_func=mse_func,
    optimum=0,
    greater_is_better=False
)
```

### Custom ROC AUC Metric
```python
ag_roc_auc_scorer = make_scorer(
    name='roc_auc',
    score_func=sklearn.metrics.roc_auc_score,
    optimum=1,
    greater_is_better=True,
    needs_threshold=True
)
```

## Key Parameters for `make_scorer`
- `name`: Name for the scorer (used in logs)
- `score_func`: The function to wrap
- `optimum`: Best possible value from the original metric
- `greater_is_better`: Whether higher values are better
- `needs_*`: Specify the type of predictions required:
  - `needs_pred`: For regression metrics (default if no others specified)
  - `needs_proba`: For probability estimates
  - `needs_class`: For classification predictions
  - `needs_threshold`: For continuous decision certainty (binary classification)
  - `needs_quantile`: For quantile regression

## Using Custom Metrics in TabularPredictor

### With leaderboard
```python
predictor = TabularPredictor(label=label).fit(train_data, hyperparameters='toy')
predictor.leaderboard(test_data, extra_metrics=[ag_roc_auc_scorer, ag_accuracy_scorer])
```

### As evaluation metric
```python

```

## Important Notes
- AutoGluon Scorers always report scores in `greater_is_better=True` form internally
- For metrics where `greater_is_better=False`, AutoGluon flips the value
- Error is calculated as `sign * optimum - score` where `sign=1` if `greater_is_better=True`, else `sign=-1`
- Error is always in `lower_is_better` format (0 = perfect prediction)
