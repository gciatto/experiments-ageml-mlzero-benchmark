This is a **regression** task.

**Input Format:** Tabular data provided in `data.csv`. The input features (`X`) are `longitude`, `latitude`, `housing_median_age`, `total_rooms`, `total_bedrooms`, `population`, `households`, `median_income`, and `ocean_proximity`.

**Prediction Output Format:** Numerical values representing the predicted `median_house_value`.

**Task Details:** The goal is to predict the `median_house_value` using the provided features. The evaluation is performed via a ten-fold cross-validation benchmark, with `rmse` (Root Mean Squared Error) as the metric (lower is better). Models must be generated by a `build_model(X_train, y_train)` factory function, returning a new, unfitted model that exposes `fit(X,y)` and `predict(X)` methods. All preprocessing must be contained within this model and fitted solely on the training data of the supplied fold. The dataset must not be shuffled, split, filtered, reordered, or sampled, and row IDs should not be added as features. Stochastic models should use `random_state/seed 42`.
